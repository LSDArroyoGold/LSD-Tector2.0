# PENDIENTE — monitoreo de batería por INA219 (voltaje/corriente vía I2C).
# Hardware nuevo: sin PiJuice, sin fuel gauge propio. Hasta que el battery
# pack con el INA219 esté armado, el sistema NO tiene watchdog de batería
# ni corte por nivel bajo: las ventanas corren siempre completas.
#
# Umbral ya definido (pack 2S2P, celdas Samsung INR18650-35E, BMS 2S 8A
# genérico con corte por sobredescarga en 2.5-3.0V±0.05V/celda):
#
#   UMBRAL_BATERIA_V=6.9   # ~3.45V/celda, ~15% de capacidad restante
#
# Motivo: deja ~0.4V/celda de margen sobre el peor caso posible de disparo

# el intervalo de 5 min entre chequeos del watchdog, y evita ciclar las
# celdas cerca de su corte de fábrica (2.65V/celda). Contrastado contra la
# curva de descarga real del fabricante a la corriente típica de este
# sistema (~0.2A/celda). Detalle completo: cuaderno de laboratorio, 14/8.
#
